# Interrupted anchor before client admission

`qualification-record-anchor-startup ID REVIEW.json` is an explicit collection-only
operation for an ended SE New Game whose common fixture-anchor settle failed
after initial world completion and before client admission. It launches, restores,
releases and clears nothing. Ordinary companion collection remains strict.

The independent operator verifies original worker/game/run attribution, exact
failed anchor intents/readbacks/trace, complete original source exports, the
actual retained process exit, native done/restoration/collection, all restored
snapshot hashes, nonempty archived/removed temporary profile and fresh native
absence of the owned worker/game/loader. Only initial dispatch/manifest files may
exist; any client intent, report, claim, component action or completed gameplay
bootstrap refuses this prefix. No missing report is synthesized.

Review kind is `qualification-anchor-startup-review`. It pins the original plan,
state, result, worker, child exit, initial dispatch, complete original Dashboard
source export, current implementation closure, strict read-only native observer,
archive inventory and separately reviewed ended-technical evidence. Review flags
must be factual; templates are neither completed review nor human authorization.
Optional operator-reported cause context has separate pinned provenance. Pose
displacement by itself establishes no cause.

The append-only diagnostic preserves one consumed actual game start and the
original known or null cumulative baseline. Execution stays failed; qualification
is not conducted, all component checks remain not_run, subject testing never
started, and provider/mod/physics acceptance remains false. Actual exit0 and an
observed nonzero exit are both retained independently of the earlier interruption.

Normal `qualification-collect` re-verifies this exact diagnostic without reading
a client report. It cannot satisfy successful qualification release. The genuine
hold remains. Any subsequent existing `pipeline-clear` review and manual launch
authority are separate operator decisions; recording never resumes a queued job.
