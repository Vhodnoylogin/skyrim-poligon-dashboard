# Ended companion before binding

`qualification-record-prebinding ID REVIEW.json` is an explicit collection-only
route for the reviewed heartbeat refusal before a companion has bound its native
run or started its inner program. It does not launch, recover, send finish,
change native state, release the hold or activate a tool baseline.

This mode preserves the earlier pre-client ConnectionRefused/known-finish and
pre-world startup predicates. It requires an actual stopped client report and
dispatch with the exact original source/plan/sequencer/executor pins and argv,
known outer-client exit2, no timeout/forced client stop, zero actions/evidence,
an empty event file, all declared cases not_run, no run/session/binding/inner
fields and no native companion claim. The initially created evidence directory
must be empty. A missing report or unknown/lost command cannot be reclassified.

Native evidence must independently prove one owned physical game start, common
world/bootstrap and exact interactive-ready admission, then the exact guardian
heartbeat recovery with original still-future deadline, observed game exit125,
worker exit125, no interactive command delivery (including finish), completed
tracked restoration/collection and archived/removed temporary profile. The
retained healthy heartbeat must identify the original worker and complete owned
process list. Fresh native process enumeration must prove the worker, client,
game and every helper including CDB dead, with no current game/loader.

The review uses schema1, kind `qualification-prebinding-review`, qualificationId,
verifiedBy, summary and true nativeCompletionReviewed, restorationReviewed,
archiveReviewed, prebindingFailureReviewed and retainHold. Supply the same exact
path/SHA256 pins as the pre-client review: plan, state, result, report, dispatch,
childExit and worker; exact profileArchivePins/profileArchiveDirectories; and
the complete current implementationPins from
`qualification_preclient.implementation_pins()`.

Also supply `endedTechnicalReview` as a path/SHA256 pin. Its independently reviewed
raw inventory must include native state/result/steps/heartbeat and exact
plan/worker/child-exit/client report/dispatch/manifest/events/logs. Every listed
raw hash (and optional exact byte count) is verified. Its native attribution,
guardian decision, clientFailure projection, no-finish and all-processes-dead
facts must match the actual retained raw records; the review cannot replace them.

The immutable prebinding-diagnostic packet records failed execution, qualification
not_conducted, every component not_run, one actual physical start and the original
cumulative count (including unknown/null). It retains the genuine hold and pins
both original inputs and the collection implementation, so later legitimate input
rollback does not rewrite old evidence. A later collection revalidates raw prefix,
archive, hashes and original absence of commands; successful release is always
false. No client binding identity, inner program, finish receipt or tested-mod
success is invented.
